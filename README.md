# TonejsDemo
音频与ToneJS (Audio and ToneJS)

A Next.js demo project showcasing Tone.js audio library features.

## Features
- Interactive synthesizer
- Drum machine (kick, snare, hi-hat)
- Audio effects (reverb, delay)
- Volume control

## Getting Started

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
